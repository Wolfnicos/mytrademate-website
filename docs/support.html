🚀 Getting Started

Q: How do I get started with MyTradeMate Portfolio?

A: Follow these steps:

  1. Download the app from Google Play Store
  2. Complete the onboarding (2-day FREE TRIAL starts automatically)
  3. Accept the disclaimer
  4. Create a Binance account (if you don't have one)
  5. Create read-only Binance API keys
  6. Add your API keys in Settings → API Configuration
  7. Start tracking your portfolio!
Q: Do I need a Binance account?

A: Yes, MyTradeMate Portfolio connects to Binance API to fetch portfolio balances and market data. We use Binance because it's the world's largest crypto exchange with:

  • High liquidity and reliable data
  • Wide selection of cryptocurrencies
  • Reliable API infrastructure

Create a free account at: https://www.binance.com

Q: How do I create read-only Binance API keys?

A: Step-by-step guide for READ-ONLY keys:

  1. Log in to Binance
  2. Go to Profile (top right) → API Management
  3. Click "Create API"
  4. Choose "System Generated" (recommended)
  5. Set permissions (CRITICAL):
    • ✅ Enable "Read Info" (view portfolio ONLY)
    • ❌ DO NOT enable "Spot & Margin Trading"
    • ❌ DO NOT enable "Futures"
    • ❌ DO NOT enable "Enable Withdrawals"
  6. Copy API Key and Secret Key
  7. Paste them into MyTradeMate Portfolio Settings → API Configuration

⚠️ IMPORTANT: Only enable "Read Info" permission. This app is for portfolio tracking only - we cannot execute any transactions.

🐛 Troubleshooting

Q: App won't connect to Binance

A: Try these solutions in order:

  1. Check your internet connection (Wi-Fi or mobile data)
  2. Verify API keys are correct (no extra spaces, copy/paste carefully)
  3. Check if API keys are still active in Binance (they can be revoked or expired)
  4. Verify "Read Info" permission is enabled in Binance
  5. Restart the app (force close and reopen)
  6. Check Binance server status: Binance Status
  7. If still failing, contact us at mytrademate.app@gmail.com
Q: Portfolio balances not showing

A: Common causes and fixes:

  • API permission missing: Verify your API key has "Read Info" enabled in Binance.
  • No holdings: Make sure you have cryptocurrency in your Binance Spot Wallet.
  • Minimum display threshold: The app hides holdings below $5 value.
  • API keys incorrect: Double-check that you copied both API Key and Secret Key correctly.
  • Refresh: Tap the refresh button on the Portfolio screen to reload data.
Q: AI predictions not available

A: Possible reasons:

  • Trial expired: Your 2-day trial has ended. Subscribe (€6.99/month or €57.50/year) to continue using the app.
  • No data available: Some trading pairs may not have sufficient historical data for AI predictions.
  • App needs update: Check Google Play Store for app updates.
