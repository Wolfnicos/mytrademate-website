🚀 Getting Started

Q: How do I get started with MyTradeMate?

A: Follow these steps:

  1. Download the app from App Store or Google Play
  2. Complete the onboarding (48h FREE TRIAL starts automatically)
  3. Accept the risk disclaimer
  4. Create a Binance account (if you don't have one)
  5. Create Binance API keys
  6. Add your API keys in Settings → API Configuration
  7. Start trading!
Q: Do I need a Binance account?

A: Yes, MyTradeMate connects to Binance API to fetch market data and execute trades. We use Binance because it's the world's largest crypto exchange with:

  • High liquidity and low fees
  • Wide selection of trading pairs
  • Reliable API infrastructure

Create a free account at: https://www.binance.com

Q: How do I create Binance API keys?

A: Step-by-step guide:

  1. Log in to Binance
  2. Go to Profile (top right) → API Management
  3. Click "Create API"
  4. Choose "System Generated" (recommended)
  5. Set permissions:
    • Enable "Read Info" (view portfolio)
    • Enable "Spot & Margin Trading" (for PREMIUM trading)
    • ⚠️ DO NOT enable "Enable Withdrawals" (CRITICAL for security!)
  6. Copy API Key and Secret Key
  7. Paste them into MyTradeMate Settings → API Configuration

📊 Trading

Q: What order types are supported?

A: MyTradeMate supports 4 order types:

  • Market Order: Executes immediately at current market price. Fast but may slip on volatile markets.
  • Limit Order: Executes only at your specified price (or better). Waits for your price, may not fill.
  • Stop-Limit Order: Triggers a limit order when price hits stop price. Good for taking profits or cutting losses.
  • Stop-Market Order: Triggers a market order when price hits stop price. Guaranteed execution at stop trigger.
Q: What are the 76 AI indicators?

A: Our AI analyzes 76 technical indicators across multiple categories:

  • Momentum: RSI, Stochastic, MACD, Williams %R
  • Trend: Moving Averages (SMA, EMA), ADX, Parabolic SAR

  • Volume: OBV, Volume SMA, Money Flow Index
  • Support/Resistance: Pivot Points, Fibonacci Retracements

All indicators are calculated in real-time and fed into our ensemble ML models for multi-timeframe predictions (5m, 15m, 1h, 4h, 1d).

🐛 Troubleshooting

Q: App won't connect to Binance

A: Try these solutions in order:

  1. Check your internet connection (Wi-Fi or cellular data)
  2. Verify API keys are correct (no extra spaces, copy/paste carefully)
  3. Check if API keys are still active in Binance (they can be revoked or expired)
  4. Verify API permissions are enabled in Binance
  5. Restart the app (force close and reopen)
  6. Check Binance server status: Binance Status
  7. If still failing, contact us at mytrademate.app@gmail.com
Q: Orders not executing

A: Common causes and fixes:

  • FREE mode (READ ONLY): Cannot place orders. Upgrade to PREMIUM or use trial period.
  • Insufficient funds: Check if you have enough balance for the trade.
  • Minimum order size: Binance requires minimum ~$10-20 USD per order.
  • API permission missing: Verify your API key has "Spot & Margin Trading" enabled.
  • Limit order not filling: Your limit price may be too far from market price. Use Market order for immediate execution.
