How MyTradeMate Works

The only portfolio tracker that runs 26 AI models and 76 indicators entirely on your device. Here's exactly how we protect your privacy while delivering powerful insights.

Local-First Architecture

Cloud trackers send your data to their servers. We don't. Everything runs on your phone.

1

You Add Your API Keys

Connect your exchange accounts using read-only API keys (no trading permissions). Keys are immediately encrypted with AES-256 and stored in your device's secure storage (iOS Keychain or Android Keystore).

Security Note: API keys never leave your device. We don't have servers to send them to. Even we can't access your keys.
2

Fetch Price Data

MyTradeMate uses your API keys to fetch real-time price data directly from exchanges. This is the only network activity—we never send your portfolio data anywhere.

What's Fetched: Current prices, historical OHLCV (Open, High, Low, Close, Volume) data, and order book depth. All calculations happen locally.
3

AI Models Analyze Locally

26 TensorFlow Lite models run on your phone's CPU/GPU to analyze patterns, trends, and risks. No cloud processing. No internet required (after data is cached).

Models Include: LSTM for sequence prediction, CNN for pattern recognition, volatility forecasting, risk scoring, and sentiment analysis (all local).
4

76 Indicators Calculated

All 76 technical indicators (25 candlestick patterns + 51 technical indicators) are calculated locally across 5 timeframes: 5-minute, 15-minute, 1-hour, 4-hour, and 1-day.

Examples: RSI, MACD, Bollinger Bands, Ichimoku Cloud, Fibonacci retracements, Doji, Hammer, Engulfing patterns, and more.
5

You Get Educational Insights

View your portfolio performance, AI-detected patterns, risk scores, and indicator signals—all presented in an easy-to-understand interface. Every insight is for educational purposes only.

Not Financial Advice: MyTradeMate provides insights based on historical data and technical analysis. You make all investment decisions.
6

Data Stays on Your Device

Your portfolio data, transaction history, and insights are encrypted and stored only on your device. Uninstall the app? Your data is gone forever. We can't recover it because we never had it.

Zero Tracking: No analytics, no telemetry, no cloud sync. Your privacy is absolute.

Security Architecture

How we protect your data without ever seeing it

Layer 1

Biometric Authentication

Face ID (iOS) or Touch ID/Fingerprint (Android) protects app access. Biometric data is handled by your device's OS—we never access or store it.

Technology: iOS Secure Enclave / Android TEE (Trusted Execution Environment)
Layer 2

AES-256 Encryption

All sensitive data (API keys, portfolio holdings, transaction history) is encrypted with AES-256 before being stored on your device.

Standard: Military-grade encryption used by banks and governments
Layer 3

Secure Storage

Encrypted data is stored in iOS Keychain (iOS) or Android Keystore (Android)—the most secure storage locations on mobile devices.

Protection: Hardware-backed encryption, isolated from other apps
Layer 4

No Cloud Backup

MyTradeMate does not use iCloud, Google Drive, or any cloud backup services. Your data remains exclusively on your device.

Trade-off: Maximum privacy, but you can't recover data if you lose your device
Layer 5

Read-Only API Keys

We recommend using read-only API keys that cannot execute trades or withdrawals. This limits damage if keys are ever compromised.

Best Practice: Enable IP whitelisting and key rotation on your exchange
Layer 6

Zero Network Telemetry

No analytics, no crash reports, no user tracking. The only network activity is fetching price data from exchanges using your API keys.

Verification: Inspect with Charles Proxy, mitmproxy, or Wireshark

Verify Our Claims

Don't trust, verify. Here's how technically savvy users can confirm our privacy promises:

  • Network Traffic Inspection: Use Charles Proxy, mitmproxy, or Wireshark to monitor all network requests. You'll see only API calls to exchanges—no analytics or tracking.
  • Device Storage Inspection: Check your device's app data directory (requires root/jailbreak). All data is encrypted—you can't read it without the app's decryption key.
  • Code Audit: While MyTradeMate is not open-source, we welcome security researchers to audit the app. Contact us for details.
